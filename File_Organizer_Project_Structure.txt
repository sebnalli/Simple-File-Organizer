FILE ORGANIZER PROJECT

PROJECT GOAL

Create a command-line file organizer that scans a folder, identifies the files inside it, groups them by type, displays a summary, and later organizes them into category folders.

This project is meant to improve your ability to work with the computer's file system using pathlib.


MAIN SKILLS TO PRACTISE

1. pathlib
2. File and folder paths
3. Loops
4. Conditionals
5. Dictionaries
6. Functions
7. Input validation
8. Sorting with key=
9. Lambda functions
10. Error handling
11. Git and GitHub workflow


PROJECT STRUCTURE

1. Create this folder structure:

file_organizer/
|
|-- main.py
|-- functions.py
|-- README.md


MAIN PROGRAM FLOW

1. Ask the user for a folder path.
2. Check that the folder exists.
3. Check that the path points to a directory.
4. Scan through the contents of the folder.
5. Ignore folders at first and only work with files.
6. Read each file's filename, extension, and full path.
7. Display the files that were found.
8. Count how many files belong to each extension or category.
9. Display a summary.
10. Later, allow the user to organize the files into folders such as Images, Documents, Code, Audio, Video, Archives, and Other.
11. Add a preview mode before moving files.
12. Handle duplicate filenames safely.

PATHLIB CONCEPTS TO USE

1. Path()
   Creates a Path object.

2. Path.exists()
   Checks whether a path exists.

3. Path.is_dir()
   Checks whether a path is a directory.

4. Path.iterdir()
   Loops through items inside a directory.

5. Path.is_file()
   Checks whether an item is a file.

6. Path.name
   Gets the full filename.

7. Path.suffix
   Gets the file extension.

8. Path.mkdir()
   Creates a folder.

9. Path.rename()
   Can be used to move or rename files.


FIRST MILESTONE

2. Confirm the folder exists.
3. Confirm it is a directory.
4. Scan through the folder.
5. Ignore subfolders.
6. Print each file name.
7. Print each file extension.

The goal of the first milestone is only to correctly inspect a folder.


SECOND MILESTONE

4. Sort the results.


THIRD MILESTONE

2. Decide which extensions belong to each category.
3. Preview where each file will be moved.
4. Ask for confirmation.

FINAL MILESTONE
